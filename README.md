# PrintAlign｜精準合併列印

以底圖搭配多欄位名單，拖拉對位並批次產生 PDF 的網頁工具。

既有作品的原始程式備份，保留原有功能與作者署名。

- 線上使用：https://a630050.github.io/PrintAlign/
- 原始碼：https://github.com/a630050/PrintAlign

## 已有功能

- 匯入圖片作為底圖。
- 匯入 Excel（.xlsx / .xls）、CSV，或手動輸入多欄位資料。
- A4 直式／橫式，以及每頁 1、2 或 4 張版型。
- 調整留白、間距及畫面縮放。
- 拖拉文字方塊對位，方向鍵微調，Shift 加速。
- 個別設定字型、對齊、字級及顏色；支援匯入 TTF／OTF 字型。
- 批次產生及下載 PDF。

以上依原始程式介面與程式碼整理，尚未重新執行完整列印驗證。

## 使用

用瀏覽器開啟 `index.html`。目前會從網路載入 Tailwind CSS、SheetJS、jsPDF 及 Google Fonts，因此首次使用需要網路；尚未包成完全離線版本。
